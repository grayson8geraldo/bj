# Blackjack Advisor — 8 Deck, S17

Продвинутый советник для игры в блэкджек с живым дилером. Использует все математически обоснованные методы для максимизации перевеса игрока.

## Методы оптимизации

| # | Метод | Описание | Вклад в перевес |
|---|-------|----------|-----------------|
| 1 | **Perfect Basic Strategy** | Оптимальное решение для каждой комбинации карт | Снижает преимущество казино до ~0.43% |
| 2 | **Hi-Lo Card Counting** | Подсчёт карт для оценки состава оставшейся колоды | +0.5–1.0% |
| 3 | **True Count** | Нормализация счёта на оставшиеся колоды | Точность подсчёта |
| 4 | **Illustrious 18** | 18 самых прибыльных отклонений от базовой стратегии | +0.1–0.2% |
| 5 | **Fab 4 Surrender** | 4 отклонения для сброса карт по счёту | +0.05% |
| 6 | **Kelly Criterion Betting** | Математически оптимальный размер ставок | Максимизация прибыли |
| 7 | **Bet Spreading (1:12)** | Большие ставки при перевесе, минимальные без него | Ключевой источник прибыли |
| 8 | **Wong In/Out** | Сигналы входа/выхода из игры по счёту | Избежание -EV рук |
| 9 | **Insurance по счёту** | Страховка только при TC >= +3 | +0.03% |
| 10 | **Ace Side Count** | Отдельный подсчёт тузов | Точность решений |
| 11 | **Session Management** | Stop-loss / win-goal для контроля дисперсии | Управление банкроллом |

## Реалистичные ожидания

> **Важно:** 70% винрейт в блэкджеке **математически невозможен** никакими легитимными методами.

- **Без подсчёта:** ~42% выигрышных рук, казино имеет перевес ~0.5%
- **С полной системой:** ~43% выигрышных рук, игрок имеет перевес ~0.3-1.5%
- **Прибыль** достигается не через винрейт рук, а через **размер ставок** при положительном счёте

Подсчёт карт переворачивает перевес в пользу игрока, но выигрыш приходит медленно (~$0.04 за руку при ставке $10).

## Установка и запуск

```bash
# Интерактивный советник для живой игры
python -m blackjack

# Симуляция для проверки стратегии
python -m blackjack.simulator --shoes 10000 -v

# Сравнение стратегий
python -m blackjack.simulator --shoes 10000 --compare -v

# Настройка параметров
python -m blackjack.simulator --decks 8 --penetration 0.50 --min-bet 10 --spread 12 --bankroll 10000
```

## Использование (живая игра)

```
> n                      # Новая рука
Your cards: A 7          # Ваши карты
Dealer upcard: 6         # Открытая карта дилера
→ DOUBLE DOWN (deviation) # Рекомендация

> h 3                    # Вам дали 3 (хит)
→ STAND                  # Стой

> c 5 K 3 7             # Считаем карты других игроков
> d 10 7                # Считаем карты дилера (в конце руки)
> r +20                 # Записываем результат (+20 выигрыш)

> b                     # Рекомендация по ставке
> s                     # Текущий статус (счёт, перевес)
> w                     # Wong сигнал (играть/уходить?)
> shoe                  # Новая колода (перетасовка)
> stats                 # Статистика сессии
```

## Как это работает

### 1. Подсчёт карт (Hi-Lo)
- Карты 2-6: **+1** (низкие — хорошо когда ушли)
- Карты 7-9: **0** (нейтральные)
- Карты 10,J,Q,K,A: **-1** (высокие — плохо когда ушли)

**True Count = Running Count / Оставшиеся колоды**

### 2. Размер ставок
```
TC ≤ 1:  1 юнит  ($10)
TC  2:   2 юнита ($20)
TC  3:   4 юнита ($40)
TC  4:   8 юнитов ($80)
TC ≥ 5: 12 юнитов ($120)
```

### 3. Ключевые отклонения
- **16 vs 10:** Стой при TC ≥ 0 (вместо хита)
- **15 vs 10:** Стой при TC ≥ +4
- **12 vs 3:** Стой при TC ≥ +2
- **Страховка:** Бери при TC ≥ +3
- **10 vs 10:** Дабл при TC ≥ +4
